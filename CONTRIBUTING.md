# Contributing

Use [GitHub issues](https://github.com/smallprimitives/byte_batcher/issues) for bugs and proposals. Include a small reproducible example for bug reports. Use the [security policy](SECURITY.md) for vulnerability reports.

Run the [test suite](README.md#tests) on Ruby 3.4 or newer before opening a pull request. Include regression tests for behavior changes. For changes to the packer or its serializers, run the [benchmark](README.md#benchmark) and share the workload, Ruby version, and results.
